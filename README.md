# CyberSecurity Bot 🔒
Automated security scanning and monitoring tool. Performs vulnerability assessment and generates detailed reports.
## 🚀 Quick Start
```bash
git clone https://github.com/madiyarmoldakhmet-ai/cybersecyritybot.git
cd cybersecyritybot
pip install -r requirements.txt\npython main.py
```
## 🛠 Tech Stack
- **Python** — automation & scanning\n- **Security frameworks** — vulnerability detection\n- **Reporting** — PDF/HTML output

* 💬 **Real-time Messaging** — Instant chat powered by Cloud Firestore.
